Experiment 1: Create a ROS2 Python Publisher and Subscriber

Aim

Set up a basic ROS2 package with Python nodes and execute them using ROS2 command-line tools.

Procedure

  1. Source the ROS2 environment (ROS2 Humble recommended).
  2. Create an ament_python package named py_pubsub.
  3. Create a publisher that sends String messages to the topic named topic.
  4. Create a subscriber callback that listens to the same topic.
  5. Add package entry points, build with colcon, and run the nodes.

Dependencies and setup

Packages / tools: ROS2 (Humble recommended), rclpy, std_msgs, colcon

Install / setup command:

sudo apt install ros-humble-ros-base python3-colcon-common-extensions
source /opt/ros/humble/setup.bash

Required files / dataset: ROS2 workspace, py_pubsub package, and demo_node.py. The full manual uses separate publisher and subscriber Python files.

ROS2 is intended for Ubuntu/Linux. Create a workspace and package with ros2 pkg create --build-type ament_python py_pubsub. Add the node and a console-script entry point in setup.py, then build using colcon build --symlink-install. Source install/setup.bash before running. The displayed code is a compact single-node topic demonstration.

Program / Code

# demo_node.py — compact publisher + subscriber in one ROS2 node
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class DemoNode(Node):
    def __init__(self):
        super().__init__('minimal_publisher_subscriber')
        self.pub = self.create_publisher(String, 'topic', 10)
        self.sub = self.create_subscription(String, 'topic', self.callback, 10)
        self.count = 0
        self.timer = self.create_timer(0.5, self.publish_msg)

    def publish_msg(self):
        msg = String()
        msg.data = f'Hello World: {self.count}'
        self.pub.publish(msg)
        self.get_logger().info(f'Publishing: {msg.data}')
        self.count += 1

    def callback(self, msg):
        self.get_logger().info(f'I heard: {msg.data}')

rclpy.init()
node = DemoNode()
rclpy.spin(node)
node.destroy_node()
rclpy.shutdown()

How to run

# Ubuntu with ROS 2 Humble installed and sourced
source /opt/ros/humble/setup.bash
# From the ROS 2 workspace root, after creating/configuring the package:
colcon build --symlink-install
source install/setup.bash
# Run the node (from a sourced ROS 2 environment)
python3 demo_node.py

Manjaro is not an officially supported ROS 2 Humble binary target. The apt command above is for Ubuntu only. On Manjaro, use a supported Ubuntu environment/VM or follow the ROS 2 source-build instructions for your exact ROS distribution.

Expected Output

The terminal repeatedly displays messages similar to: Publishing: Hello World: 0 and I heard: Hello World: 0, followed by increasing numbers.

Result

Thus, a basic ROS2 Python publisher/subscriber node was created, built, and executed using ROS2 command-line tools.

Notes and limitations

This compact single-node demonstration combines publishing and subscribing to the same topic. The full manual uses separate publisher_member_function.py and subscriber_member_function.py files with console-script entry points.

Experiment 4: Image Processing Using OpenCV

Aim

Convert an image to grayscale, apply Gaussian blur, and detect edges using OpenCV in Python.

Procedure

  1. Read the input image.
  2. Convert BGR to grayscale.
  3. Apply Gaussian blur.
  4. Detect edges using Canny and display the results.

Dependencies and setup

Packages / tools: opencv-python, matplotlib, numpy

Install / setup command:

python -m pip install opencv-python matplotlib numpy

Required files / dataset: cat.jpg (place it beside the Python script)

Run with Python. The image filename in the code must match the file you provide.

Program / Code

import cv2
import matplotlib.pyplot as plt

img = cv2.imread("cat.jpg")
if img is None:
    raise FileNotFoundError("Place cat.jpg beside this script.")

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)
edges = cv2.Canny(blur, 50, 150)

titles = ["Original", "Grayscale", "Blurred", "Edges"]
images = [cv2.cvtColor(img, cv2.COLOR_BGR2RGB), gray, blur, edges]
cmaps = [None, "gray", "gray", "gray"]

fig, axes = plt.subplots(2, 2, figsize=(9, 7))
for ax, title, image, cmap in zip(axes.flat, titles, images, cmaps):
    ax.imshow(image, cmap=cmap)
    ax.set_title(title)
    ax.axis("off")
plt.tight_layout()
plt.show()

How to run

# Put cat.jpg in the same directory as the script
python -m pip install opencv-python matplotlib numpy
python3 experiment4.py

Input check: The filename must match exactly. If the image is missing or unreadable, the script raises FileNotFoundError.

Expected Output

A 2×2 display shows the original image, grayscale image, blurred image, and Canny edge map.

Result

Thus, grayscale conversion, Gaussian blurring, and edge detection were performed using OpenCV.

Notes and limitations

Requires opencv-python and matplotlib. Place an image named cat.jpg in the same folder as the script.

Experiment 5: Video Processing Using OpenCV

Aim

Process each frame of a video stream with simple transformations in real time.

Procedure

  1. Open the video file.
  2. Read frames in a loop.
  3. Convert each frame to grayscale.
  4. Display processed frames; press q to exit.

Dependencies and setup

Packages / tools: opencv-python

Install / setup command:

python -m pip install opencv-python

Required files / dataset: Sample.mp4 (place it beside the Python script)

Run on a desktop with a display because cv2.imshow() opens a video window. Press q to quit.

Program / Code

import cv2

cap = cv2.VideoCapture("Sample.mp4")
if not cap.isOpened():
    raise FileNotFoundError("Place Sample.mp4 beside this script.")

while True:
    ret, frame = cap.read()
    if not ret:
        print("Video Ends")
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Processed Frame", gray)

    if cv2.waitKey(30) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()

How to run

# Put Sample.mp4 beside the script
python -m pip install opencv-python
python3 experiment5.py
# Press q in the video window to quit

Platform note: A desktop session with video-window support is required. In a headless terminal/SSH session, OpenCV's display window may not open.

Expected Output

A video window displays the grayscale frames. Press q to stop; the program prints Video Ends when the video finishes.

Result

Thus, video frames were processed using OpenCV and a grayscale transformation.

Notes and limitations

Requires opencv-python and a video file named Sample.mp4 in the same folder.

Program / Code

# Short demonstration of adapting ResNet18.
# This snippet does not train or evaluate the model.
import torch
import torch.nn as nn
from torchvision import models

model = models.resnet18(weights="DEFAULT")
for param in model.parameters():
    param.requires_grad = False

model.fc = nn.Linear(model.fc.in_features, 10)
model.eval()

with torch.no_grad():
    sample = torch.randn(1, 3, 224, 224)
    prediction = model(sample).argmax(dim=1).item()

print("Predicted class index:", prediction)

Experiment 10: L1 Structured Pruning on ResNet18

Aim

Apply L1 structured pruning to convolutional layers in ResNet18 and evaluate the pruned model.

Procedure

  1. Load pretrained ResNet18.
  2. Apply L1-norm structured pruning to convolution filters.
  3. Remove pruning reparameterizations.
  4. Evaluate the pruned model and optionally fine-tune.

Dependencies and setup

Packages / tools: torch, torchvision

Install / setup command:

python -m pip install torch torchvision

Required files / dataset: Pretrained ResNet18 weights download on first use. Full accuracy evaluation uses CIFAR-10, which downloads automatically.

The short snippet demonstrates pruning. For measured test accuracy, add a CIFAR-10 test DataLoader and evaluate the pruned model. Use the same device for model and input tensors.

Program / Code

import torch
import torch.nn.utils.prune as prune
from torchvision.models import resnet18, ResNet18_Weights

model = resnet18(weights=ResNet18_Weights.DEFAULT)

for module in model.modules():
    if isinstance(module, torch.nn.Conv2d):
        prune.ln_structured(
            module, name="weight", amount=0.3, n=1, dim=0
        )
        prune.remove(module, "weight")

print("L1 structured pruning completed.")

How to run

python -m pip install torch torchvision
python3 experiment10.py

Runtime note: Pretrained weights download on first run. The shown snippet demonstrates structured pruning; it does not prove a speedup or report test accuracy. To measure accuracy, add a consistent evaluation DataLoader and move both model and batches to the same device (CPU or CUDA).

Expected Output

Prints L1 structured pruning completed. This confirms that the pruning operations ran; it is not an accuracy measurement.

Result

The full lab experiment applies 30% structured pruning to convolutional layers and evaluates the pruned ResNet18 on CIFAR-10.

Notes and limitations

The manual's evaluation code uses CUDA tensors directly and has device/dataloader omissions in the extracted text. This compact version demonstrates pruning only; it does not evaluate accuracy.
